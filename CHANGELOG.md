# Изменения

## 0.4.1

- Громкость больше не может сохраниться для другого трека: ссылка на файл берётся только по id самого трека, а не из аудиоэлемента плеера. Допуск сверки длительности файла сужен до 1,5 с.
- Кэш замеров сброшен: значения прошлых версий могли относиться к другому файлу. Размер кэша ограничен 5000 треками.
- Зависшая загрузка больше не блокирует замеры: загрузка обрывается, если сервер молчит 15 с (общий лимит 3 мин), запрос ссылки и декодирование тоже ограничены по времени. Воспроизведение это не затрагивает: аддон качает отдельную копию файла только для замера.
- Исправлен замер треков, которые плеер ещё не загрузил (следующий трек при быстром переключении, «Измерить весь плейлист»): в текущей версии Яндекс Музыки аддон не находил, как запросить ссылку на файл.
- Исправлен скачок громкости при переключении трека: громкость нового трека больше не применяется к ещё звучащему предыдущему (аддон пересчитывает её посреди трека только для трека, который плеер уже запустил).
- Ещё не измеренный трек начинается с типичной громкости ваших уже измеренных треков (с запасом в тихую сторону), а не без приглушения: при быстром переключении нет резкого скачка вверх, после замера громкость поправляется на несколько дБ.
- Заранее измеряются 3 следующих трека, а не 1. Замер играющего трека не ждёт фоновых загрузок, а загрузки пролистанных треков обрываются.
- Остановка «Измерить весь плейлист» сразу прерывает текущую загрузку.
- Треки, которые пролистали, пока они ждали в очереди, не скачиваются.
- Выключение AudioNorm в настройках возвращает всё как было: убирает записанные аддоном данные громкости со всех треков, останавливает загрузки и сразу пересчитывает громкость играющего трека встроенной нормализацией. Повторное включение возвращает измеренные значения.
- MP3 декодируется по частям во время загрузки: в памяти не больше ~60 МБ звука при любой длине трека (раньше файл декодировался целиком, часовой микс занял бы больше гигабайта). Результат совпадает с замером целого файла с точностью до 0,01 LUFS.
- Новый переключатель «Измерять длинные треки (больше 15 мин)», по умолчанию включён: выключите, чтобы не скачивать такие файлы. Длинные треки в других форматах (M4A и т. п.) и треки длиннее 3 часов не измеряются; остальные форматы декодируются целиком с ограничением размера файла.
- Пока в Яндекс Музыке выключена «Нормализация громкости», аддон ничего не скачивает и не задерживает старт треков.
- Изменяются только импортированные треки: треки с другим источником, даже с id в формате UUID, не затрагиваются.
- Плеер ожидается через публичный `pulsesyncApi.playerInstance` вместо внутреннего `_waitForPlayer`.
- В README добавлен раздел о том, что аддон делает с данными.
- Меньше фоновой работы: хук плеера берётся напрямую, без обхода объектов; очередь проверяется только при изменениях; статус индикатора считается только в режиме отладки.

## 0.4.0

- Первая публичная версия.
- Измерение громкости импортированных треков по EBU R128 и передача её встроенной нормализации.
- «Измерить весь плейлист» в настройках.
- Режим отладки: индикатор появляется только при проблеме, по клику копируется отчёт.

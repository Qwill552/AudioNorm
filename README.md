# AudioNorm

**Выравнивает громкость импортированных треков в Яндекс Музыке.**

AudioNorm дополняет встроенную нормализацию громкости, а не заменяет её. Для треков из каталога нормализация берёт громкость из данных Яндекса. У импортированных треков этих данных нет, поэтому она приглушает их все одинаково, и громкий трек остаётся громче тихого.

AudioNorm сам измеряет громкость импортированных треков по EBU R128 и передаёт её встроенной нормализации. Звук она обрабатывает как обычно, своей обработки аддон не добавляет.

## Как включить

1. Включите **AudioNorm** в аддонах PulseSync и перезапустите Яндекс Музыку.
2. В плеере нажмите на качество звука (FLAC или AAC внизу справа) и включите **Нормализация громкости**. Без неё AudioNorm ничего не меняет.

![Настройки звука → Нормализация громкости](./assets/sound-settings.png)

Новые треки измеряются при первом прослушивании. Чтобы измерить весь плейлист сразу, включите его и нажмите «Измерить весь плейлист» в настройках AudioNorm.

## Ручная установка

Скачайте репозиторий и положите его содержимое в папку `%APPDATA%\PulseSync\addons\audionorm`.

## Ошибки

Включите «Режим отладки» в настройках AudioNorm. При проблеме слева внизу появится индикатор, клик по нему копирует отчёт. Приложите отчёт к [issue](https://github.com/Qwill552/AudioNorm/issues).

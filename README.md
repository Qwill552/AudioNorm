# AudioNorm

**Выравнивает громкость импортированных треков в Яндекс Музыке.**

AudioNorm дополняет встроенную нормализацию громкости, а не заменяет её. Для треков из каталога нормализация берёт громкость из данных Яндекса. У импортированных треков этих данных нет, поэтому она приглушает их все одинаково, и громкий трек остаётся громче тихого.

AudioNorm сам измеряет громкость импортированных треков по EBU R128 и передаёт её встроенной нормализации. Звук она обрабатывает как обычно, своей обработки аддон не добавляет.

***Очень не нравилось, что на мои загруженные треки не работает выравнивание громкости, поэтому навайбкодил такую шнягу)***

## Как включить

1. Включите **AudioNorm** в аддонах PulseSync и перезапустите Яндекс Музыку.
2. В плеере нажмите на качество звука (FLAC или AAC внизу справа) и включите **Нормализация громкости**. Без неё AudioNorm ничего не меняет.

![Настройки звука → Нормализация громкости](./assets/sound-settings.png)

Новые треки измеряются при первом прослушивании, следующие три трека — заранее, пока играет текущий. Чтобы измерить весь плейлист сразу, включите его и нажмите «Измерить весь плейлист» в настройках AudioNorm.

## Что аддон делает с данными

- Для замера скачивает файл импортированного трека с серверов Яндекс Музыки по той же ссылке, что получает плеер. Файл не сохраняется: после замера остаются два числа (громкость и пик), они хранятся локально в Яндекс Музыке.
- Ничего не отправляет на сторонние серверы, аналитики нет.
- Треки из каталога не трогает и не скачивает.
- Пока выключена «Нормализация громкости», ничего не скачивает и не задерживает старт треков.
- MP3 декодирует по частям, поэтому даже часовой микс занимает в памяти не больше ~60 МБ. Длинные треки (больше 15 минут) измеряются, пока включён «Измерять длинные треки»: выключите его, чтобы не скачивать такие файлы. Длинные треки в других форматах (M4A и т. п.) и треки длиннее 3 часов не измеряются.
- Выключение AudioNorm в настройках сразу возвращает обычную громкость.

## Ручная установка

Скачайте репозиторий и положите его содержимое в папку `%APPDATA%\PulseSync\addons\audionorm`.

## Ошибки

Включите «Режим отладки» в настройках AudioNorm. При проблеме слева внизу появится индикатор, клик по нему копирует отчёт. Приложите отчёт к [issue](https://github.com/Qwill552/AudioNorm/issues).
